================================================================================
QUICK SETUP STEPS
================================================================================

1. Go to: https://railway.app/dashboard

2. Create new project from GitHub repo

3. Select repository: fusion-cars

4. Set Root Directory: BE_FusionCars (IMPORTANT!)

5. Go to "Variables" tab

6. Add all 7 variables above (copy Key and Value)

7. Click "Deploy"

8. Wait 3-5 minutes for deployment

9. Get your Backend URL from "Service URL"

10. Use that URL for frontend NEXT_PUBLIC_API_URL

================================================================================
TESTING YOUR BACKEND
================================================================================

After deployment, test with these curl commands:

1. Health Check:
   curl https://YOUR-RAILWAY-URL/api/health

2. Get Cars:
   curl https://YOUR-RAILWAY-URL/api/cars

3. Expected Response:
   Health: {"status": "Server is running", "database": "Connected"}
   Cars: [{"_id": "...", "name": "Car Name", ...}]

================================================================================
IMPORTANT NOTES
================================================================================

Root Directory: MUST be set to BE_FusionCars
   - This tells Railway where your backend code is located
   - Without this, deployment will fail

Node.js Version: Set to 18 or 20
   - Go to Settings tab
   - Find Node.js Version
   - Select latest stable

Start Command: Should auto-detect as "npm start"
   - Manually set if needed: node src/index.js

Build Command: Leave blank
   - Not needed for Node.js deployments
