# Multi-Image Gallery - Quick Start Guide (5 Minutes)

## ⚡ Get Started Instantly

### Step 1: Access the Gallery (10 seconds)
1. Click **"Gallery"** in the navbar
2. Or visit: `http://localhost:3000/gallery`
3. Choose a car from the grid

### Step 2: Browse Images (20 seconds)
1. **Main Lightbox** shows large image
2. Click **Previous/Next arrows** to navigate
3. See image counter (e.g., "1 / 20")
4. Click any **thumbnail** to jump to that image

### Step 3: Filter by Type (15 seconds)
1. See filter buttons at top:
   - All | Exterior | Interior | Engine | Dashboard | Wheels | Other
2. Click a filter (e.g., "Interior")
3. Thumbnails update instantly
4. Shows count per type (e.g., "Interior (3)")

### Step 4: Zoom & Inspect (20 seconds)
1. Click **Zoom In button** to magnify
2. Or use **zoom slider** for precise control
3. **Zoom level** shows at bottom right
4. Click **Zoom Out** to reduce zoom
5. Reset when switching images

### Step 5: Download Image (10 seconds)
1. Click **Download button** (blue)
2. File saves to device
3. Named: `{CarName}-{type}-{number}.jpg`
4. High resolution (800-1920px)

### Step 6: Share Image (10 seconds)
1. Click **Share button** (green)
2. Choose app: WhatsApp, Email, Messenger, etc.
3. Title and description included
4. Fallback to copy-to-clipboard

### Step 7: Watch Videos (15 seconds)
1. Scroll down to **Videos section**
2. See embedded YouTube walkthroughs
3. **Previous/Next** buttons to navigate
4. Full player controls available
5. 360° view links available

## ⚙️ Controls Guide

### Navigation
- **Previous Arrow:** Go to last image
- **Next Arrow:** Go to next image
- **Auto-Loop:** Last image → First image
- **Thumbnail Click:** Jump to any image
- **Image Counter:** Shows position (X / Total)

### Zoom Controls
- **Zoom In Button:** Increase magnification
- **Zoom Out Button:** Decrease magnification
- **Zoom Slider:** Precise zoom adjustment
- **Range:** 1.0x (normal) to 3.0x (max)
- **Display:** Current zoom level shown
- **Reset:** Changes on image switch

### Action Buttons
- **Download:** Save high-res copy to device
- **Share:** Open share menu for messaging apps
- **Fullscreen:** Expand to full screen (desktop)
- **Filter Buttons:** Switch image categories

### Information Display
- **Image Counter:** Current / Total images
- **Image Type:** Category badge (Exterior, Interior, etc.)
- **Zoom Level:** Current magnification
- **Car Name & Details:** At top of gallery
