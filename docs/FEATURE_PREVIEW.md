## 8. Feature Highlights

### When 1 Car Selected
```
"Select at least 2 cars to compare"
- Charts hidden
- Export buttons disabled
- Only single car details visible
```

### When 2-3 Cars Selected
```
✅ Charts visible with animations
✅ All export buttons enabled
✅ Full specs table displayed
✅ Highlights view available
✅ Save button active
```

### When 3 Cars Selected
```
✅ "Add Car" button shows "Maximum cars selected"
✅ Can still remove and replace cars
✅ All features remain fully functional
```

## 9. Data Flow Example

### User Journey
```
User Opens /advanced-compare
        ↓
"Select First Car" → Modal Opens
        ↓
Filters: "BMW" + "Petrol" → Shows 3 BMW Petrol cars
        ↓
Clicks "BMW M5" → Added to slot 1
        ↓
"Add Second Car" → Modal Opens
        ↓
Sorts: "Rating (Highest First)" → Shows best-rated cars
        ↓
Clicks "Mercedes AMG" → Added to slot 2
        ↓
Charts Display ✨
Specs Table Shows ✨
        ↓
"Add Third Car" → Modal Opens
        ↓
Filters: "Audi" → Shows Audi cars
        ↓
Clicks "Audi RS5" → Added to slot 3
        ↓
User Clicks "Export CSV" → Downloads comparison.csv
        ↓
User Clicks "Save Comparison" → Saved to localStorage
        ↓
User Returns Later → Can retrieve saved comparison
```

## 11. Color Scheme

### Dark Theme (Default)
- **Background:** `#0a0a0a` (Primary Black)
- **Cards:** `#1a1a1a` (Primary Dark)
- **Borders:** `#2a2a2a` (Accent Charcoal)
- **Text Primary:** `#ffffff` (White)
- **Text Secondary:** `#8a8a8a` (Accent Stone)
- **Highlights:** `#d4af37` (Accent Gold)

### Badges & Highlights
- **Best Price:** Gold background, black text
- **Best Mileage:** Green background
- **Best Rated:** Blue background
- **Interactive:** Gold hover effects
